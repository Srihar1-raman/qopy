# qopy — Copy text from your Mac screen

Canonical page: https://qopy.combif1am.site/

Select text in images or videos and copy it to your clipboard. qopy is a menu bar app for macOS 14 and later, with on-device text recognition.

## How it works

1. Press Command + Shift + 2 to start capture.
2. Click and drag over an area containing text.
3. Press Command + V to paste.

## Install

1. [Download qopy for Mac](https://github.com/Srihar1-raman/qopy-releases/releases/latest/download/qopy.dmg).
2. Open the .dmg, drag qopy into Applications, and open it.
3. When prompted, enable Screen Recording and Accessibility in System Settings → Privacy & Security for screen capture and the global shortcut. These permissions can be revoked there.

If macOS blocks the app, verify the download came from the linked GitHub release. Only if you trust it, use Open Anyway in System Settings → Privacy & Security and follow the macOS prompts.
